# UI Audit — Tessera AI Agent Console

**Surface:** 3 routes (`/chat`, `/dashboard`, `/overview`) across 3 Next.js apps
**Date:** 2026-11-21 16:40 UTC
**Reviewer:** Hermes (impeccable audit)
**Method:** full-page screenshots @1440×900 + 390×844, deterministic detector scans, source review (`packages/shared-ui/src/dq.css`, `apps/*/app/globals.css`, components)

## Anti-Patterns Verdict

**Verdict: does it look AI-generated? Mostly yes — not because it is broken, but because it is the default.**

The build is coherent and real: one authored token system, one icon set, a status bar that reads
like instrument data. But the _identity_ is the category default — indigo-600 + slate + Inter +
rounded soft-shadow cards — so stripped of the Vietnamese copy it could be any AI chat SaaS demo.
The category-interchangeable test fails: nothing in the palette, type, or surface language says
"console for observing an agent's tool calls."

### What does not read as generated

- Status bar: real route + session id in mono, pause chip, "Federation: Ready" — this is the one
  element with a point of view.
- Error state: pill with icon + "Thử lại" action, not a raw red block.
- Vietnamese copy and the agent's own "thinking" label — specific, not boilerplate.
- Authored 27-icon SVG set, no emoji, no icon library.

## Findings by Priority

### P1 — Identity is interchangeable

1. **Palette** — indigo/slate is the AI default. No color is drawn from the product's world
   (agent activity, tool calls, observability).
2. **Type** — Inter + system fallback. No display voice; headings and body share one tone.
3. **Overview structure** — two stacked 4-up card grids with icon+heading+arrow-list. The page
   explains the architecture as eight equal cards; nothing is sequenced, nothing is emphasized.

### P2 — Soft-UI default and template patterns

4. **Card language** — every container is a rounded card with the same border and shadow. No
   contrast between instrument surface (data) and reading surface (prose).
5. **KPI row** — four equal numbers with equal weight; the page's job is triage, but nothing is
   prioritized.
6. **Decoration** — dot grid and glass blur add texture without meaning; both cost contrast and
   paint.
7. **Rhythm** — spacing collapses to 4px multiples (82% of gaps); dense and even, no hierarchy by
   whitespace.

### P3 — Small frictions

8. Gradient avatar/logo gradients — trope, and the only non-token colors.
9. Sparkle/bolt icon repeated on every badge — reads as decoration, not semantics.
10. Sub-44px touch targets; hover-only actions unreachable on touch.
11. Two English-ish hints in an otherwise Vietnamese UI ("Shell → module → store", "4 bước").

## Systemic Issues

- **Soft-card default**: one material for every job. The product needs at least two — a dense
  instrument surface for telemetry and a calm reading surface for prose.
- **Equal-weight layouts**: grids of same-size cards are used as page structure, so the eye has no
  entry point. Hierarchy is carried only by type size.
- **Default palette as brand**: tokens are disciplined, but the chosen values are the category
  default. Discipline without a point of view still reads as generated.
- **Decoration without function**: dot grid, glass blur, gradients, sparkle icons — each is a
  visual tic that does not encode state.

## Recommended Actions

Run in this order; each is a real command, not an audit-time fix:

1. `/impeccable colorize` — replace indigo/slate with a palette drawn from the product's world;
   keep the semantic error/success values.
2. `/impeccable typeset` — give headings a display voice distinct from body; keep mono for data.
3. `/impeccable distill` — delete dot grid, glass blur, gradients; collapse the Overview's two
   card grids into one sequenced structure.
4. `/impeccable bolder` — amplify the one distinctive element (the status bar) into the page's
   identity anchor; give the dashboard a triage hierarchy instead of four equal KPIs.
5. `/impeccable polish` — final pass: spacing rhythm, touch targets, `aria-live`, remaining hints.

## Positive Findings

- Authored token system with dark parity — no hardcoded colors except one gradient stop.
- Status bar with route/session/federation state — real instrument feel, the strongest element.
- Error and empty states are designed, not defaulted.
- Vietnamese copy throughout; no lorem ipsum, no placeholder text.
